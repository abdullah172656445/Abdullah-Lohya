# Crop Yield Analysis

## Files
- `Crop_Yield_Analysis.ipynb`: completed Jupyter notebook with code and executed outputs.
- `crop_yield.csv`: original dataset supplied with the assignment.
- `crop_yield_cleaned.csv`: cleaned dataset produced by the analysis.
- `crop_yield_trend.png`: saved yield trend chart.

## How to run
1. Keep all files in the same folder.
2. Open `Crop_Yield_Analysis.ipynb` in Jupyter Notebook or JupyterLab.
3. If needed, install dependencies with: `pip install pandas matplotlib`
4. Choose **Kernel > Restart & Run All**.

The notebook follows the steps in the supplied activity sheet.
