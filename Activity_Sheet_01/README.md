# Data Analysis Activity Sheet 01 — Answers

## Dataset 1: Pakistani E-Commerce Data
1. **Most popular product category:** Home Decor (30 orders).

4. **Most used payment method:** Cash on Delivery (29 orders).
5. A bar chart of average order value by city is included in the Jupyter notebook.

## Dataset 2: Student Lifestyle & Study Habits
1. **Average number of study hours:** 4.40 hours.
2. **Who sleeps more on average:** Females (6.80 hours; males average 6.39 hours).
3. **Screen time and sleep hours:** Very weak positive linear relationship (Pearson correlation r = 0.052), effectively almost no linear relationship.
4. A histogram of daily transport cost is included in the Jupyter notebook.
5. **Average internet usage by gender:** Males average 6.00 hours; females average 5.32 hours.
